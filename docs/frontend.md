# Frontend Guidelines

## 1. Stack

- Vue 3
- Inertia
- TypeScript
- TailwindCSS
- shadcn-vue

## 2. Principles

- Keep pages thin.
- Extract reusable components.
- Use TypeScript types.
- Avoid unnecessary global state.
- Prefer consistent UI patterns across products.

## 3. Product Experience

Even if products are separate, the user experience should feel coherent across the ecosystem.
